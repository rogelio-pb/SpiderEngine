Tutorial Steps

This document outlines the sequence of lessons in the DirectX Tool Kit Getting Started tutorial.

Each lesson is documented on the DirectXTK wiki.

Lesson Sequence

# Lesson Wiki Page Summary
0 Prerequisites Getting Started Verify required tools: Visual Studio, Windows SDK, vcpkg, and Git
1 Project Setup Getting Started Create a new Direct3D 11 project using the d3d11game_vcpkg template
2 Building the project Build the project and resolve any dependencies
3 Adding DirectXTK Adding the DirectX Tool Kit Integrate DirectXTK into the project via vcpkg
4 Sprites and Textures Sprites and textures Render 2D sprites using SpriteBatch
5 Drawing Text Drawing text Render text using SpriteFont
6 Simple Rendering Simple rendering Draw simple triangle primitives
7 3D Shapes 3D shapes Use GeometricPrimitive for standard 3D shapes
