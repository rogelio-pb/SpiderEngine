Detailed Description

Funciona como una caja de memoria dentro de la tarjeta de video.

La tarjeta de video no puede leer directamente la memoria normal de la computadora. Para que pueda usar los datos de una figura primero hay que copiarlos a una caja especial dentro de la tarjeta. Esta clase se encarga de crear esa caja, llenarla, actualizarla, usarla para dibujar y borrarla al terminar.
